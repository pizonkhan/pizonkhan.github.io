# pizonkhan.github.io

My personal portfolio, built with Next.js and deployed to GitHub Pages.

I wanted the project pages to actually show the work instead of just linking out to a repo,
so each one runs a real, interactive version of what's behind it: a New York home sales map
you can click into, a bird species classifier you can watch narrow down a prediction, that
kind of thing.

## Running it locally

```bash
npm install
npm run dev        # localhost:3000
npm run build      # static export to out/
```

## Stack

Next.js 15 (static export), TypeScript, Tailwind CSS, deployed via GitHub Actions to GitHub
Pages.
